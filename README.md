# PaperShot

PaperShot 是一个本地 Windows 桌面工具。API、兴趣关键词、总结偏好和邮箱都在打开后设置。仅使用 Python 标准库，无需 pip 安装依赖。

![PaperShot](PaperShot.png)

## 启动

需要 Windows 和 Python 3.10+（安装时保留 Tcl/Tk 组件）。将项目克隆或下载到有写入权限的位置，双击 `Start.bat`，或运行 `python app.py`。

## 首次设置

1. 打开“兴趣与设置”，填写 Chat Completions 兼容的 API 基础地址、Key 和模型名称。基础地址通常带 `/v1`，例如服务商文档中的 `https://…/v1`；也可直接填完整 `/chat/completions` 地址。原生 Claude Messages / Gemini generateContent 接口需经兼容网关接入。
2. 点击“测试 API”。模型应支持至少 32K 上下文、中文和 JSON 输出。API 调用按服务商规则计费；程序不会提供模型额度。
3. 填写研究关键词，逗号或换行分隔，多个关键词按“或”检索。建议使用英文短语；中文偏好描述可以帮助模型排序，但不会自动把中文检索词翻译成英文。arXiv 分类可留空。
4. 默认最近 14 天、最多 100 篇候选、选取总共 10 篇；按相关分排序，同分时优先更新的论文。不是“每个分类 10 篇”。相关论文不足时不会强行凑数。
5. 填写 SMTP 服务器、端口、加密方式、登录账号、邮箱授权码、发件邮箱和收件邮箱。请按邮箱服务商的说明填写，SMTP 通常需要额外开启。“发送测试邮件”会向你填写的收件邮箱发出真实测试邮件。
6. 保存设置。可先生成预览，确认后点击“发送当前这期到邮箱”。
7. 勾选自动发送，默认选择“当天首次联网即发送”：当天尚未发送时，所需服务可以连接就立即开始生成或补发。也可选“到达指定时间后发送”，按北京时间设定时间。保存生效。程序必须保持运行；关闭窗口后不会推送，最小化不受影响。

## 详细总结

默认内容：背景与研究问题、动机、方法创新（输入/输出/流程）、实验设计（数据集/任务/基线/指标/消融）、结果、局限、阅读建议及兴趣关联。默认约 800–1400 中文字，资料不足时不强行凑字数。可在设置中补充要求。

优先从 arXiv HTML 读取正文；不支持 HTML 时降级到摘要，不自动下载/解析 PDF。HTML 文字提取可能丢失图表和公式。长正文会截取开头和结尾，中间省略，明确标注来源范围。未提供的数据集或实验细节要求模型写“提供的内容未说明”。总结是模型输出，重要事实仍需核对原文。

## 再来 10 篇与历史

“再来 10 篇”按当前兴趣和检索窗口继续选取未生成过的 10 篇，只保存预览，不自动发邮件。需要时点发送。当前版本使用按钮触发，尚未接入自然语言聊天命令。

成功总结的论文才进入已读记录；版本更新不视作新论文。历史中可打开往期、导出 Markdown、再次发送。手动预览也会被记为已读，因此后续每日任务不再重复选择它们。摘要不足可扩大天数或候选上限。

## 定时与失败恢复

支持两种自动发送方式：

- **当天首次联网即发送（默认）**：每天尚未发送时，一旦检测到所需服务可连接，立即开始推送流程，不必等到设定时间。
- **到达指定时间后发送**：到北京时间指定时间后开始；若电脑离线，恢复联网后立即补发。

约每 10 秒在后台检测所需服务的 TCP 连接，不阻塞界面、不提交凭据。日报已生成时只检查 SMTP；尚未生成时还检查 API 与 arXiv。恢复连接会跳过一小时重试等待。网络连接成功不等于身份验证或服务请求必定成功；真正发送仍需完成登录等步骤。

没有生成日报时，联网后需先检索、评分、生成总结，完成后发出；已有未发送日报则直接重试该期邮件。一天成功发出一封自动日报，反复断网重连不会重复发送成功的日报。手动预览不会替代自动日报。服务持续可连接但推送失败（例如额度或授权码问题）时，每小时重试一次；自动失败只更新状态，不弹窗阻塞。跨北京时间零点开始新一天的判断，不补发以往日期的积压日报。可点击“运行今日定时任务”立即重试。

如少数论文总结失败，本期包含失败说明，只将成功论文记入已读，不自动重做已发日报。若全部失败，则不保存本期、不发邮件。可手动重试生成。

SMTP 接受不等于最终进入收件箱，请检查垃圾邮件。极少数情况下服务器收件成功后连接中断/程序崩溃，重试可能重复发送，无法保证端到端恰好一次。

## 数据与凭据

- `data/settings.json` 保存配置，API Key 和 SMTP 授权码由 Windows DPAPI 加密，仅当前 Windows 账户可解密。不要分享自己的 data 文件夹。
- 兴趣、邮箱地址、论文总结和已读记录保存在本地，历史使用 SQLite。
- 模型提供商会收到兴趣描述、论文摘要/正文；SMTP 服务商接收邮件正文。
- 程序不提供后台云服务，不设置系统开机自启。第一版来源为 arXiv，尚未接入 PubMed、期刊数据库、收藏反馈或聊天控制。

## 扩展与开发

`core.py` 管理检索、模型、总结、数据库和邮件，`app.py` 管理窗口及运行期间的定时器。可逐步扩展数据源、反馈评分、PDF 阅读或聊天触发入口。

测试：`python -m unittest discover -s tests -v`

仓库隐私检查：`python scripts/check_repository.py`。提交前可运行 `python scripts/check_repository.py --staged` 检查 Git 暂存区。GitHub Actions 会在推送和拉取请求时自动运行测试及仓库检查，无需真实 API Key 或邮箱配置。

克隆后运行一次 `git config core.hooksPath .githooks`，可启用提交前自动隐私检查。此检查拦截常见凭据和运行数据文件，但不能代替人工检查；本地真实配置仅应存放在已忽略的 `data/` 文件夹。

后续更新建议通过分支和拉取请求维护。提交前检查 `git diff --cached --stat`，确认只包含预期代码。不要使用 `git add -f` 强行添加被忽略的本地配置。`.gitignore` 用于排除未跟踪文件，不能移除已经提交的秘密；本项目的首次提交不包含运行时数据。

arXiv 接口说明：https://info.arxiv.org/help/api/user-manual.html

## 更新旧版

关闭旧窗口，将新版文件覆盖到原程序文件夹即可。保留原 `data` 文件夹，已存 API、邮箱和历史自动沿用；原先启用自动发送的用户将默认使用“当天首次联网即发送”，需要定时请在设置中切换。压缩包不包含个人配置。

## 桌面快捷方式

在项目文件夹运行 `Create-DesktopShortcut.ps1` 可创建带专用图标的 PaperShot 桌面快捷方式，通过 pythonw 直接打开窗口，不显示命令行窗口（脚本需要能找到 Python 的 pythonw.exe）。快捷方式指向当前程序文件夹；移动程序后请重新运行脚本。快捷方式文件不提交到仓库。
